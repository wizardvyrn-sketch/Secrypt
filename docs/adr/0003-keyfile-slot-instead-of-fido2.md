# ADR-0003: FIDO2 キー未所持の間、持ち運び用スロットに USB キーファイルを使う

- Status: Proposed
- Date: 2026-10-25

## Context
FIDO2 セキュリティキーを現在所持していない。TPM スロットはそのPC限定なので、
PC故障時や他PCで開く手段として、紙の復旧コード以外にも日常的に使える「持ち運べる第二要素」が必要。

## Options
1. USB キーファイル（256bit）＋パスワード — 購入不要。コピー可能な点が弱み
2. パスキー PRF（スマホ / Windows Hello パスキー） — 取り出し不可で強いが、Windows ネイティブアプリからの対応状況が不確実
3. 認証アプリ TOTP — 検証側に秘密を置く方式のため暗号鍵にならず不可
4. パスワード単独スロット — 「ファイル流出で総当たりされない」原則に反するため不可

## Decision
`keyfile` スロットを MVP に追加し、FIDO2 の代わりとする。パスワード側の Argon2id は重めの設定にする。
パスキー PRF は Phase 0 で調査し、使えればスロット種別として追加する。FIDO2 キー購入後は `fido2` スロットへの置き換えを推奨する。

## Consequences
- ＋ 追加購入なしで「ファイル流出・PW流出でも復号不可」「単一障害点なし」を満たす。
- ＋ キースロット方式のため、後から FIDO2 に移行してもデータの再暗号化は不要。
- − キーファイルはコピーされても気づけない。紛失時はスロット削除＋VMK ローテーションで対応する。
- − Vault と同じ場所に置く運用ミスを防ぐため、アプリ側で検出・警告が必要。
