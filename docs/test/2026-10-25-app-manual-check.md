## 見つかった問題と対応

| 問題 | 対応 |
|---|---|
| 詳細パネルの入力欄が内容の幅に縮む | 横幅いっぱいに広げる（最大 680px） |
| スクロールバーが標準の明るい色でテーマから浮く | 細い暗色のつまみに変更 |
| 鍵と設定ウィンドウで「閉じる」が下端に詰まる | 高さを拡大 |
| 解錠失敗時に鍵ファイルのパスワード欄が残る | 失敗時に消去 |
