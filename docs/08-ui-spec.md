### 1.1 アプリ名と起動時ロゴ画面（2026-11-01）

アプリ名は **Secrypt**（exe は `Secrypt.exe`、インストール先は `%LOCALAPPDATA%\Programs\Secrypt`）。ただし次の 2 つは旧名 NewPWManageTool のまま残す。

- 多重起動防止の Mutex 名 `Local\NewPWManageTool-<id>`（改名前の exe と同じ Vault を同時に開かせないため）

### 1.2 版の表記

表示用の版は `1.00A` 形式（機能追加で数字、不具合修正で英字を進める）。`Directory.Build.props` の `DisplayVersion` が唯一の定義で、アセンブリのメタデータとして埋め込み、`Services/AppVersion` が読む。.NET の `Version` は数値形式のため数字部分に合わせる（1.00A → 1.0.0）。

- 画面に出すのは **S-02 解錠画面だけ**（見出し `SECRYPT` の下に `Ver. 1.01A`）。
- 配布パッケージ名（`Secrypt-1.01A-win-x64`）と README.txt も `DisplayVersion` を使う。ログ・診断情報は .NET の `Version` のまま。

## 3. S-01 初期設定

中央のカード（幅 600px）に `STEP n / 3` と細い進捗バー。

| STEP | 内容 | 入力・検証 | 次へ進むと |
|---|---|---|---|
| 1 | このPCで開くための PIN | TPM の利用可否を表示（● 利用可 / ◆ 利用不可と理由）。PIN 6 文字以上、確認一致 | TPM スロットを登録。「TPM を使わずに進む」も選べる（利用可の場合は確認ダイアログ） |
| 2 | USB メモリの鍵ファイルとパスワード | パスワード 10 文字以上・確認一致、保存先（保存ダイアログ）。保存先が Vault と同じフォルダ／同じ同期フォルダ／PC 内ドライブなら琥珀色で警告（同じフォルダは不可） | 鍵ファイルを書き出してスロット登録。「QR コードを印刷」と「鍵ファイルを保存した」チェックが現れ、チェック後に次へ |
| 3 | 復旧コード（紙に書き写す） | 36 文字（4 文字×9 組）を大きく表示。ランダムな 2 組の書き写し確認。「コードを隠して確認する」チェック | 確認一致で保存し、S-03 へ |

- 保存は STEP 3 の完了時に 1 回だけ。途中で離れた場合は何も保存しない。
- 下部に保存先のパスを表示。

【実装済み R-01】手順は `SetupService`（`SetupFlow`）、画面の状態は `SetupViewModel`。完了時に既に Vault があれば上書きしない。

## 4. S-02 解錠

中央に「PW VAULT」（グラデーション文字）と「ロックされています」。カード内に切り替えタブ。

| タブ | 表示条件 | 入力 | 補足 |
|---|---|---|---|
| PIN（この PC） | TPM スロットがあるとき（既定） | PIN | TPM の回数制限の説明を表示 |
| 鍵ファイル | 鍵ファイルのスロットがあるとき | 鍵ファイル（前回の場所を自動入力。「選ぶ」で変更）、パスワード | 「印刷した QR のテキストを入力する」で `PWMK1:…` を入力しても可 |
| 復旧コード | 常に | 36 文字（区切り・大小・O/0・I/L/1 の違いは許容） | 解錠後に鍵の再登録を勧める |

- Enter で解錠。失敗時は琥珀色で理由を表示し、入力欄を消去。
- 3 回連続で失敗すると待ち時間（15 秒から倍増、最大 300 秒）。
- 成功時は S-03 へ。【実装済み R-15】最終使用日は日付が変わったときだけ記録し、その保存ではバックアップを回さず保存回数も進めない。
- 【実装済み】TPM のスロットがあっても、この PC の TPM のものでなければ（PC の買い替え・TPM のクリア後・別の PC）PIN タブを無効にし、上部に「この PC の TPM は登録されていません…」と案内する。

| 失敗の理由 | 表示 |
|---|---|
| PIN 違い | 「PIN が違います。（TPM の失敗回数が 1 回増えました。31 回でロックされ、10 分ごとに 1 回減ります）」 |
| TPM ロック中 | 時間をおくか、鍵ファイル／復旧コードで解錠するよう案内 |
| TPM 不可・封印データ不正 | TPM クリアの可能性と、鍵ファイル／復旧コードでの解錠・TPM 再登録を案内 |
| 鍵違い | 「解錠できませんでした。パスワード・キーファイル・復旧コードを確認してください。」 |
| 別の Vault の鍵ファイル | 「この鍵ファイルは、この Vault に登録されていません」 |
| 改ざん・破損 | バックアップ（.bak1 など）からの復元を案内 |

【実装済み R-14】結果は `UnlockResult` で受け取り、文言は `UserMessages` の対応表で決める。「別の Vault 用」と「削除済み」の鍵ファイル、USB 未挿入、復旧コードの書き間違いと別のコードを区別する。
【改善予定 R-09】タブはスロットプロバイダの一覧から作る。

## 5. S-03 一覧・詳細

```
┌ ツールバー: [＋ 新規] [ブラウザから取り込む]           (状態メッセージ) [鍵と設定] ┐
├ 一覧（幅 320） ─────────┬ 詳細 ─────────────────────────────────┤
│ 🔍 検索                  │ ENTRY / NEW ENTRY                       │
│ n ITEMS                  │ タイトル（大きめ）                        │
│ ▌タイトル                │ ユーザー名 [コピー]                       │
│   ユーザー名 · ホスト名   │ パスワード ●●●● [表示] [生成] [コピー]   │
│                          │  └ 生成パネル（長さ・文字種・強さの目安）  │
│                          │ URL [開く] / メモ / タグ                  │
│                          │ 作成・更新日時                            │
│                          │ [削除]                  [元に戻す] [保存] │
└──────────────────────────┴─────────────────────────────────────────┘
```

| 機能 | 仕様 |
|---|---|
| 検索 | タイトル・ユーザー名・URL・タグの部分一致（大文字小文字を区別しない）。件数を `n / 全 ITEMS` で表示 |
| 並び順 | タイトル順 |
| 新規・保存・削除 | Ctrl+N / Ctrl+S。タイトルか URL のどちらかが必須。削除は確認ダイアログ（直前の状態は .bak1 に残る旨を表示） |
| パスワード表示 | 既定は伏せ字。表示ボタンで切り替え。項目を開き直すと伏せ字に戻る |
| 生成 | 長さ（既定 20）、小文字・大文字・数字・記号（各 1 文字以上を保証）、紛らわしい文字を除く。強さの目安（ビット）を表示。生成すると表示状態になり、「保存」で確定 |
| コピー | パスワード・ユーザー名をコピー。クリップボード履歴（Win+V）・クラウド同期に載せない形式を付け、設定秒数（既定 20 秒）後に、まだ同じ内容なら消去 |
| URL を開く | http(s) のみ既定のブラウザで開く |
| ブラウザから取り込む | 手順説明（Chrome / Edge のエクスポート方法、CSV は平文なので削除する旨）→ ファイル選択 → 件数確認（同じ URL＋ユーザー名の登録済みは除外、パスワードが空の行はスキップ）→ 取り込み → CSV を削除（既定オン） |
| Ctrl+F | 検索欄へ移動 |

【実装済み R-03】編集中に別の項目を選ぶ・新規・手動ロック・終了するときに、未保存の変更があれば「保存／破棄／戻る」を確認する（自動ロック時は破棄してログに記録）。
【実装済み R-04】保存に失敗した変更はメモリ上でも元に戻し、入力欄の内容は残す。
【実装済み】取り込みの確認画面: 登録済みと同じ（URL・ユーザー名・パスワードが一致）ものは取り込まず、パスワードが違うものは取り込んで「古い方を削除してください」と知らせる。CSV の中の完全な重複は 1 件にまとめる。

## 6. S-04 鍵と設定

| 区分 | 内容 |
|---|---|
| 解錠方法 | スロット一覧（アイコン・ラベル・種別・登録日・最終使用日 or「まだ使っていません」） |
| ＋ 鍵ファイルを追加 | パスワード入力（10 文字以上・確認）→ 保存先 → 作成 → QR 印刷の確認 |
| ＋ この PC の TPM を登録 | PIN 入力（6 文字以上・確認）→ 封印。既存の TPM スロットは置き換え（PC 買い替え・TPM クリア後の再登録） |
| 復旧コードを作り直す | 確認 → 新しいコードを表示 → 1 組の書き写し確認 → 古い復旧コードを無効化 |
| 選んだ方法を削除 | 確認 → 削除。「復旧コード＋他 1 つ以上」を満たさなくなる削除は拒否 |
| 設定 | 自動ロック（1〜120 分、既定 5）、クリップボード消去（5〜300 秒、既定 20）。閉じるときに保存 |
| Vault 情報 | パス、Vault ID、保存回数、項目数 |

【実装済み R-18】診断情報（版・ランタイム・ログの場所、「ログフォルダを開く」）と「詳細ログを記録する」を追加した。TPM の解錠方法は「この PC の TPM + PIN」「他の PC（またはクリア前）の TPM + PIN」と表示する。
【実装済み】「この PC の TPM を登録」は、この PC の TPM の方法だけを置き換える（PIN の変更）。他の PC の TPM の方法は残す。使用中の鍵ファイルの上に新しい鍵ファイルは作れない。

## 7. 共通の振る舞い

| 項目 | 仕様 |
|---|---|
| 自動ロック | 無操作が設定分続いたとき、画面ロック・ユーザー切替・リモート切断時、スリープ時。ロックで VMK と画面上のパスワードを破棄し、自分が置いたクリップボード内容を消去して S-02 へ |
| 手動ロック | タイトル帯のロックボタン、Ctrl+L |
| 閉じる | ロックしてから終了 |
| 画面キャプチャ | メインウィンドウ・ダイアログ（復旧コードの表示、鍵ファイルのテキスト入力など）・「鍵と設定」は、スクリーンショット・録画・画面共有に映らない（`WDA_EXCLUDEFROMCAPTURE`、`Services/CaptureProtection`）。Debug ビルドのみ開発用に解除可。起動時ロゴ画面は秘密を表示しないため除外しない |
| 解錠方法の削除・復旧コードの作り直し・PIN の変更 | 確認画面で「PC 内の自動バックアップ（直近 5 回分）も削除し、それより前には戻せなくなる」「PC の外のコピーでは古い方法でまだ開ける」と伝える。自動バックアップを削除できなかった場合は、パスを示して手動での削除を案内する（docs/02 T4b） |
| QR 印刷 | 紙に印刷できるプリンターを選ぶよう案内する。PDF・XPS・OneNote・FAX などファイルに出力するプリンターを選ぶと警告し、既定は「やめる」 |
| 処理中 | Argon2id・TPM の処理中は画面全体を覆い、「処理中」の文言と細い進捗バーを表示 |
| 未処理例外 | 【実装済み R-19】ログに記録 → ロック →「ログフォルダを開く／続ける／終了」 |
| 多重起動 | 【実装済み R-16】同じ Vault を開く 2 つ目の起動は止め、既存のウィンドウを前面に出す |

【実装済み R-02】処理中（鍵ファイル作成など）に自動ロックの条件を満たした場合は、処理の完了を待ってからロックする。処理中は「鍵と設定」なども操作できず、閉じるボタンは完了後に閉じる。
【実装済み】ロック時は「鍵と設定」とダイアログ（復旧コードの表示を含む）を閉じる。

## 8. 文言の方針

- 短く、指示しすぎない。結果と次の行動を 1〜2 文で伝える（例:「PIN が違います。」→ 回数制限の補足）。
- 「Vault」「スロット」「キースロット」などの内部用語や、`.bak1` などの内部のファイル名は画面に出さない。パスワードのデータのファイルは「保管ファイル（vault file）」、開け方は「解錠方法」「鍵ファイル」「復旧コード」、自動の世代バックアップは「自動バックアップ（直近 5 回分）」と言い、戻し方は操作手順書の「困ったとき」へ案内する（Vault ID 等の情報表示を除く）。
- 失敗時の文言は `UserMessages`（Application）に集約した。

### 8.1 表示言語（日本語 / English）（2026-11-01）

- 画面の文言はすべて日本語と英語を対で持ち、起動中に切り替えられる。【実装済み R-11 の代替】`Strings.resx` ではなく、文言を書く場所で対にする方式にした（キーの対応ずれが起きず、2 言語なら読みやすいため）。
  - C#: `L.T("解錠する", "Unlock")`（`PwManager.Core.Localization.L`。Core の例外のうち画面に出るもの＝復旧コード・鍵ファイルのテキスト・TPM のエラーも対象）
  - XAML: `Text="{c:T Ja='解錠する', En='Unlock'}"`（`Controls/T`。切り替えると表示中の文言も変わる）
- 切り替えは **S-01 初期設定の最初の手順** と **S-02 解錠画面** の右上の「日本語 / English」。切り替えるとその画面を作り直す（初期設定は途中の入力を捨てないよう最初の手順でだけ出す）。
- 選んだ言語は `settings.json` の `Language`（`"ja"` / `"en"`）に保存する。未設定なら Windows の表示言語が日本語のとき日本語、それ以外は英語。
- 対象外: 起動時ロゴ画面（英字のみのデザイン）、診断用 CLI `pwm` と `setup.cmd` の出力（日本語のみ。`setup.ps1` が `pwm diag tpm` の日本語出力で判定しているため）、ログ。
- テストは常に日本語の文言で確かめる（`L` の既定は日本語。アプリだけが起動時に設定から切り替える）。
