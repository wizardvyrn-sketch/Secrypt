# ADR-0001: Vault 鍵をマスターパスワードから導出しない

- Status: Proposed
- Date: 2026-10-25

## Context
パスワード由来鍵のみだと、Vault 流出時にオフライン総当たりが可能で、パスワード流出時には即時に復号される。

## Decision
ランダムな VMK で Vault を暗号化し、VMK は LUKS 型の複数キースロットで包む。
各スロットの KEK は、ファイル外にある高エントロピー秘密（TPM 内部鍵 / FIDO2 hmac-secret / 紙の復旧コード）を必須要素とする。
パスワード/PIN は二要素目として組み合わせる。

## Consequences
- ＋ ファイル単体・パスワード単体・両方の流出でも復号不可。
- ＋ パスワード変更・端末追加が VMK 再暗号化なしで可能。
- − ハードウェア依存。喪失対策として複数スロット（復旧コード必須）を強制する必要がある。
- − 実装が従来方式より複雑（Platform 層の PoC が必要）。
